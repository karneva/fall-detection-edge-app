# 실패 원인 분석 (failure_v1)

규칙 엔진만으로 재생한 단계 A에서 놓친 낙상, 제때가 아닌 탐지, ADL 오탐을 원인별로 셌습니다.
다음 작업(Day 7 포즈 모델 개선, 규칙 개선, 장면 분할)을 무엇부터 할지 정하려는 분석입니다.
결정 기준은 분석 전에 [ROADMAP Day 5](ROADMAP.md)에 적어 두었습니다.

## 요약

- **놓친 낙상 185개 중 약 2/3가 포즈 검출 문제입니다.** 사람이 보이는데 YOLOv8-pose가 누운 사람을 검출하지 못합니다.
  - 자동 분류: 포즈 122개(66%), 규칙 46개(25%), 라벨상 일어남 17개(9%)
  - 무작위 30개를 프레임으로 직접 확인: 포즈 모델 미검출 21개(70%), 규칙 6개(20%), 일어남 2개, 가림 1개.
    자동 분류와 28/30 일치
- **같은 영상에서 서 있을 때는 잡고 누우면 놓칩니다.**
  - 놓친 낙상: 낙상 전 3초 동안 사람 검출률 0.93~1.00, 낙상 뒤 0.44~0.73 (데이터셋별)
  - 제때 탐지한 낙상: 낙상 뒤 0.85~1.00
- **MCFD가 놓친 낙상의 61%(112/185)입니다.** 높은 곳에 단 광각 카메라 8대가 매트리스 위 낙상을 찍은 데이터라, 작고 멀리 누운 사람이 많습니다.
- **규칙 원인 중 가장 뚜렷한 유형은 카메라 시선 방향으로 누운 경우입니다.** 머리나 발이 카메라를 향하면 bbox가 세로로 길게 남아(정규화 세로/가로 2.6~4.1) "누움" 조건(1.6 미만)을 넘지 못합니다.
- **ADL 오탐 77개 중 절반 가까이(34개)는 앉은 채로 끝나는 경우입니다.** 의자 21, 소파 6, 침대 4, 바닥 3.
  침대·소파에 누운 경우는 12개(16%)뿐이고, 65개는 정지 꼬리(마지막 프레임 20초 반복) 안에서 알람이 났습니다.
- **결정:**
  - Day 7 포즈 모델 개선(P)은 예정대로 진행하고, 누운 자세·광각 원거리·어두운 장면을 목표로 합니다.
  - 규칙 원인은 직접 확인으로 20%라 기준(약 1/3) 미만이므로 규칙 개선(R)은 추가하지 않습니다.
  - 침대·소파 누움 오탐이 16%라 장면 분할(S)도 선택으로 남깁니다.

## 방법

- **대상:** 평가 클립 712개(낙상 472, ADL 240). 단계 A(규칙만), progression과 같은 재생(15Hz, EMA, 정지 꼬리 20초)
- **도구:** `training/experiments/failure_analysis.py`. 재생하면서 프레임마다 엔진 상태를 기록합니다.
  기록 항목은 사람 검출 여부, 워밍업 카운터, 진입 신호 4종(급하강·자세·어깨 하강·높이 감소), 누적 타이머, 붕괴 확정입니다.
- **놓친 낙상 원인 판정 순서.** 창은 낙상 구간 [fall_start, fall_end + 2초]입니다.
  1. 창 안 프레임 절반 이상이 미검출이거나 품질 0.15 미만이면 `pose_lost_during_fall`
  2. 보이는 프레임 절반 이상이 워밍업(12프레임) 미달이면 `detection_flicker`. 검출이 한 번 끊기면 카운터가 0이 됩니다.
  3. 부분 신체 판정이 절반 이상이면 `partial_body`
  4. 진입 신호 2개 이상이 잠깐 있었지만 0.35초 연속을 못 채우면 `signals_too_brief`
  5. 클립 끝 1초의 bbox 세로/가로 중앙값이 1.6 이상이면 `lying_bbox_not_flat`
  6. 그 밖은 `weak_motion_signals`
- **ABNORMAL에 들어갔는데 LEVEL1까지 못 간 경우:**
  - 회복으로 해제됐고 라벨상 일어났으면 `got_up_per_label`, 아니면 `false_recovery`
  - 해제 없이 끝났는데 마지막 프레임이 미검출이면 `lost_after_fall`: 엔진은 미검출 프레임에서 정지 누적과 타임아웃을 진행하지 않습니다.
  - 해제 없이 끝났는데 붕괴 확정이 안 됐으면 `timeout_unconfirmed`
- **제때 아닌 탐지:** MODEL_STUDY의 엄격 기준을 씁니다. 지금은 `replay.timing`으로 실행기에 들어 있습니다.
- **직접 확인:** 놓친 낙상 무작위 30개(seed 0)와 ADL 오탐 77개 전부를 확인했습니다.
  - 그림: 영상 프레임 6장에 키포인트와 bbox를 겹쳤습니다(`render_sheet`). 낙상은 시작 전후·끝·클립 끝, ADL은 진입 전후·클립 끝입니다.
  - 태깅: Claude(비전 모델)가 그림을 보고 태그를 달았습니다. 사람이 다시 확인하지 않았으므로, 대표 사례 일부를 직접 보고 확인할 것을 권합니다.
  - 태그 파일: [eval/annotations/failure_v1_manual_tags.json](../eval/annotations/failure_v1_manual_tags.json)

| 기준 | 결과 | 결정 |

포즈 모델 개선의 기대 효과 상한:

- 포즈 묶음 122개가 모두 회복된다고 가정하면 규칙 상한은 0.608에서 최대 약 0.87((287 + 122) / 472)까지 오릅니다.
- 실제로는 회복된 프레임도 규칙 조건(진입 신호, 정지)을 넘어야 하므로 이보다 낮습니다.

## 한계

- **임계값:** 원인 판정의 비율 기준(0.5)과 창 길이는 사전에 정한 값이고, 결과를 본 뒤 바꾸지 않았습니다.
  경계에 걸린 사례는 다른 원인으로 분류될 수 있습니다.
- **직접 확인 표본:** 놓친 낙상 30개는 표본이라, 비율의 95% 신뢰구간이 넓습니다(포즈 70%면 약 ±16%p).
- **태깅 주체:** 직접 확인 태그는 Claude가 프레임 6장을 보고 달았습니다. 영상 전체를 본 것이 아니므로,
  짧은 순간(예: 잠깐 일어남)은 놓칠 수 있습니다.
- **정지 꼬리:** ADL 오탐 대부분과 일부 탐지는 정지 꼬리 가정에 의존합니다.
  현장 녹화셋(Day 9)에서 다시 확인해야 합니다.
- **클립 단위 대상 전환:** 클립 파일에 프레임별 대상 전환 기록이 없어 재생에서 전환 후 1초 유예가 빠져 있습니다.
  추출기에 기록을 추가했으므로, 다시 추출한 뒤에 반영됩니다.

## 재현

```bash
python -m training.experiments.failure_analysis --out dataset/_experiments/failure_v1 --render-missed 30 --render-adl all
```

`dataset/_experiments/failure_v1/`에 다음 파일이 생깁니다.

- `records.json`: 클립별 결과와 원인
- `summary.json`, `summary.md`: 자동 분류 집계
- `sheets/`: 확인용 그림
- `sheets.json`: 그림을 그린 표본 목록
